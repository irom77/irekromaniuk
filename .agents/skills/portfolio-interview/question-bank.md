# Question bank

Ask one question at a time. Pick 2–4 per session from one track plus at most one core question. Each question lists the evidence to probe for; ask follow-ups until the answer has a situation, Irek's own action, a result, and a public source or a note that there is none.

Standard follow-ups (use on any answer):

- "What did you personally do, versus the team?"
- "How did you know it worked? What changed afterwards?"
- "Is there a public project or portfolio section that shows this?"
- "What would you do differently now?"
