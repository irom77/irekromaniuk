Security automation & orchestration

Tell me about a security automation you designed and built.

I designed and built an automated threat-response system that inserted firewall block rules in real time when security infraction rates crossed defined thresholds. It blocked threats every day with no recorded false positives.

SituationIn one role, our firewall rules were reactive. They were added ad hoc or pulled from static public blocklists, and updates were infrequent, which left us blind to new, active threat actors. The firewall was already classifying security events; it just had no dynamic enforcement.

ActionI owned the whole initiative. I set the infraction velocity thresholds, designed the pipeline, and wrote the automation code from scratch to insert block rules in real time. Instead of relying on outside threat feeds, it acted on the firewall's own event classification, so it responded to what attackers were actually doing against us.

ResultDay-to-day metrics showed it actively dropping threats every day, and we never recorded a single false positive. It was effective enough that authorized penetration tests had to be explicitly allowlisted before they could run.
