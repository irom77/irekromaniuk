Racegow: from raw DVR to a race-ready highlight.

I built Racegow to find my fastest three consecutive clean laps across raw FPV recordings. It reads the on-screen timer, detects gate crossings, filters crashes and invalid laps, and exports a frame-accurate highlight.

The lap analysis is deterministic. I can ask an AI coding agent to run the tool, inspect its verification images, and help with the workflow; the timing and lap checks stay grounded in the video.
